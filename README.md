# 📖 Story - Digital Couple's Memory Scrapbook

A secure, interactive web-based couple's memory scrapbook featuring an integrated PIN passcode lock screen, timeline layout, background audio player, and Cloudinary cloud storage integration for persistent image retention.

## 🚀 Features
* **Secure Access:** PIN passcode lock screen to keep memories private.
* **Interactive Timeline:** Chronological display of special moments and milestones.
* **Ambient Audio:** Integrated HTML5 audio player for background music.
* **Cloud Storage:** Cloudinary API integration for permanent media storage.

## 🛠️ Tech Stack
* **Backend:** Python, Flask, Gunicorn
* **Frontend:** HTML5, CSS3, JavaScript
* **Cloud API:** Cloudinary
